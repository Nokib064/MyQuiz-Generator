# MyQuiz – Trivia Quiz Application

## Project Overview

MyQuiz is a web-based trivia quiz application built with HTML, CSS, and vanilla JavaScript. It retrieves trivia questions from the Open Trivia Database (Open Trivia DB) and allows users to test their knowledge across different categories and difficulty levels.

Players answer multiple-choice questions against a countdown timer and receive their final results at the end of the quiz.

## Features

- Select from different trivia categories.
- Choose a difficulty level: Easy, Medium, or Hard.
- Fetch 10 multiple-choice questions from Open Trivia DB.
- Randomly shuffle answer options.
- 15-second countdown timer for each question.
- Immediate feedback for correct and incorrect answers.
- Automatic handling of unanswered questions when time expires.
- Track quiz progress with a progress bar.
- Display final score and percentage.
- Performance messages based on the final score.
- Save the highest score using browser localStorage.
- Play Again functionality.
- Loading indicators and error handling.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling and responsive layout.
- JavaScript (Vanilla JavaScript) – Application logic and interactivity.
- Open Trivia DB API – Trivia questions and categories.
- Browser localStorage – Persistent best-score storage.

## Getting Started

1. Download or clone the project.
2. Open the project folder.
3. Open the main HTML file in a web browser.
4. Select a trivia category and difficulty level.
5. Click Start Quiz to begin.

An active internet connection is required to retrieve questions from the Open Trivia DB API.

## API Reference

This application uses the Open Trivia Database API.

Website: https://opentdb.com/

API documentation: https://opentdb.com/api_config.php

## Project Limitations

- Questions require an internet connection to load.
- The best score is stored locally in the browser.
- Clearing browser storage will remove the saved best score.

## Future Improvements
